# Portfolio — ฐนน เพ็ญวิเชียร

เว็บพอร์ตโฟลิโอแบบเล่าเรื่อง: เด็กที่นั่งเล่นเกมในห้องเรียน → เริ่มสงสัย → กลายเป็นคนสร้างเกม
เว็บจริง: https://nokkawow.github.io/portfolio/

> ไฟล์นี้คือ "คู่มือทีม" — ใครจะมาช่วย (คนหรือ AI) อ่านไฟล์นี้ก่อนแก้อะไร

---

## 1. ของที่ใช้ (Tech Stack)

| อะไร | ใช้ทำอะไร | โหลดจาก |
|---|---|---|
| HTML / CSS / JavaScript ธรรมดา | ทั้งเว็บ (ไม่มี React, ไม่มี build step) | — |
| [GSAP 3.12.5](https://gsap.com) + ScrollTrigger | แอนิเมชันทั้งหมด + ผูกฉากกับการเลื่อน | cdnjs |
| [Lenis 1.1.13](https://github.com/darkroomengineering/lenis) | เลื่อนหน้าแบบนุ่ม | jsdelivr |
| Web Audio API | เสียงสังเคราะห์ (ยังไม่มีไฟล์เสียง) | ในเบราว์เซอร์ |
| Google Fonts: Noto Sans Thai, Mali | ฟอนต์ (ชั่วคราว) | Google Fonts |
| GitHub Pages | Deploy (branch `main`, โฟลเดอร์ root) | — |

ไอเดียเอฟเฟกต์ยืมจาก [Aceternity UI](https://ui.aceternity.com/components) และ [21st.dev](https://21st.dev/community/components)
แต่**ห้ามก๊อปมาตรงๆ** (พวกนั้นเป็น React + Tailwind) → ให้เขียนใหม่ด้วย GSAP ใน `js/effects.js`

## 2. โครงไฟล์

```
index.html          โครงหน้า (layer ทั้งหมดอยู่ใน .stage ที่ pin ไว้)
css/style.css       สไตล์ทั้งหมด (ธีม, board, nav, responsive)
js/content.js       ⭐ ข้อความ/รูป/ลิงก์ทั้งเว็บ — แก้เนื้อหาที่นี่ที่เดียว
js/main.js          ไทม์ไลน์หลัก (ScrollTrigger ตัวเดียวคุมทั้งเว็บ), loader, nav bar, เมนู
js/scene.js         วาดห้องเรียน + ตัวละคร (SVG แยกเลเยอร์)
js/character.js     ฟิสิกส์ตัวละคร: ตามองเมาส์, ปาปากกา, ragdoll, ดึงหัว/หางม้า, เขียนหนังสือ
js/board.js         กระดาน: เขียนคำถาม, วาด/ถูลบ, แปรงลบอัตโนมัติและตรวจว่าลบด้วยมือครบ
js/workspace.js     ห้องทำงาน, ปฏิทิน และผลงานแนวนอนภายในจอคอม
js/mascot.js        มาสคอตแอบดูขอบจอ (จับ/ยก/โยน/ดัน)
js/workspace.js     ห้องทำงาน + จอคอม: ปฏิทิน, กองภาพผลงาน, หน้าติดต่อในจอ, กล้องซูมเข้าจอ
css/monitor.css     สไตล์ในจอคอม/ห้องทำงาน (ขนาดอิงจอคอมด้วย cqw/cqh)
assets/characters/rig/  ตัวละครแยกชิ้น (ฐาน/ตา/ม่านตา/หางม้า) ให้ตาขยับ กะพริบ หางม้าแกว่งได้
js/effects.js       Text Generate, Flip Words, 3D Card, Sparkles
js/sound.js         เสียงสังเคราะห์ + ปุ่มเปิด/ปิด
assets/logo.png     โลโก้มาสคอต (วงกลม)
assets/mascot/      มาสคอต 3 ท่า: cross (กอดอก) / stand (ยืน) / squat (นั่งยอง)
assets/projects/    รูปเกม แยกโฟลเดอร์ละเกม
assets/src/         ไฟล์ต้นฉบับ/สเก็ตช์ (ไม่ขึ้น git)
```

ลำดับโหลดสคริปต์ (สำคัญ): `content → sound → effects → scene → character → board → mascot → main`

## 5. สเปกรูปสำหรับ AI เจนภาพ

**สไตล์รวม:** มังงะขาวดำ เส้นหมึกคม แรเงาด้วยสกรีนโทน (จุด) + สีม่วงแค่จุดเด่น

**ฉาก / พื้นหลัง**
- ขนาด **1920×1080** (16:9) — จุดสำคัญให้อยู่กลางภาพ เพราะมือถือจะครอปด้านข้างออก
- ต้องการให้กล้องซูมได้ → เจนใหญ่กว่านั้นได้ยิ่งดี (เช่น 3840×2160)

**ตัวละครที่ต้องขยับได้** → ต้อง**แยกเลเยอร์** เป็น PNG พื้นโปร่งใส ขนาดแคนวาสเท่ากันทุกไฟล์ และวางตำแหน่งตรงกัน (ซ้อนกันแล้วเป็นตัวเต็ม):
```
hair-back.png   ผมด้านหลัง
ponytail.png    หางม้า (แกว่งได้)
face.png        หน้า (ไม่มีตา ปาก คิ้ว)
eye-white-L/R   ตาขาว ซ้าย/ขวา
iris-L/R        ตาดำ ซ้าย/ขวา (ขยับตามเมาส์)
brows.png       คิ้ว
mouth.png       ปาก (ถ้ามีหลายอารมณ์: mouth-normal / mouth-surprised / mouth-dizzy)
bangs.png       ผมหน้า
torso.png       ตัว + เสื้อ
arm-L/R.png     แขน
```
ภาพตัวละครชิ้นเดียว (ไม่แยกเลเยอร์) ใช้ได้แค่เป็นภาพนิ่ง — **ขยับตา/หัว/ragdoll ไม่ได้**

**รูปผลงาน:** JPG กว้างประมาณ 1280px, สัดส่วน 16:9 · รูปแรกของแต่ละเกม = รูปหลัก

## 6. วิธีแก้งานที่พบบ่อย

- **แก้ข้อความ / เพิ่มเกม / แก้ช่องทางติดต่อ** → `js/content.js` อย่างเดียว
  - เพิ่มเกม = ก๊อปบล็อกใน `projects` แล้วแก้ค่า
  - Nav bar, แปรงลบคั่น, สไลด์ จะสร้างเองอัตโนมัติ
- **เปลี่ยนมุมกล้อง** → `SHOTS` ใน `js/main.js` (พิกัดอิงฉาก 1920×1080)
- **เพิ่มเอฟเฟกต์** → เขียนฟังก์ชันใน `js/effects.js`
  - ต้องเช็ก `Effects.reduce` เพื่อปิดเองเมื่อผู้ใช้ตั้งค่าลดการเคลื่อนไหว
- **หลังแก้ CSS/JS** → เพิ่มเลข `?v=` ใน `index.html` ทุกไฟล์ (กันเบราว์เซอร์จำไฟล์เก่า)

## 7. รันในเครื่อง / Deploy

```bash
py -3 -m http.server 5510
```
แล้วเปิด http://localhost:5510 (ต้องรันผ่านเซิร์ฟเวอร์ เปิดไฟล์ตรงๆ บางอย่างจะไม่ทำงาน)

**Deploy:** commit → GitHub Desktop กด **Push origin** → รอ 1–2 นาที → เว็บอัปเดตเอง

### อัปเดตฉาก v27 (26 ก.ย. 2569)
- `assets/characters/student-front.png`, `student-back.png`, `student-turn.png`: ภาพ PNG พื้นใสจาก ImageGen อิงมาสคอตเจ้าของ ผม/ตาสีม่วง เสื้อเชิ้ตขาวแขนสั้น กางเกงดำ เข็มขัด ถุงเท้าขาว รองเท้า ไม่มีปีกหรือเสื้อคลุม
- ท่าหน้าตรงนั่ง, ด้านหลังบนเก้าอี้ทำงาน, เก้าอี้หันประมาณ 90 องศาและมองกล้อง เป็นภาพ 2D เปลี่ยนผ่านตาม scroll ไม่ใช่โมเดล 3D
- ภาพหน้าตรงขยับกับสปริงลำตัวเดิม แต่ตา/ผม/สีหน้าในภาพยังไม่ได้แยก rig; ห้ามอ้างว่าลูกเล่นตา/ผมเดิมทำงานบนภาพใหม่นี้แล้ว
- workspace.js คำนวณกรอบจอจากขนาดเวทีและ camera.p; ไม่ขยายทั้ง workspace จนเนื้อหาถูกตัด ส่วนภาพเกมใช้ object-fit:contain
- scene-refinement.css คุมการจัดวางในจอคอม; เนื้อหายาวเลื่อนภายในได้ และหน้ามือถือจัดภาพเหนือข้อความ
- ตรวจผ่าน browser ที่ 1920×1080, 1366×768, 800×450, 375×812; ตรวจ nav ข้ามฉากและย้อนจากผลงานมาท่าหัน ไม่มี console error ในการตรวจครั้งนี้
- ข้อจำกัด QA: ยังไม่ได้ทดสอบโหมด reduced-motion ผ่าน browser และยังไม่ได้ไล่ลูกเล่นเดิมทุกอันครบอีกครั้ง
